# MuJoCo model strategy

Do not hand-author a replacement YAM arm model until there is evidence the vendor model is wrong.

Baseline:
- upstream YAM MJCF;
- upstream gripper model;
- exact upstream commit hash.

Then build a *scene* around the baseline:
- two arm base transforms;
- work surface;
- extrusion / fixture;
- camera frames;
- task objects.

`vendor_snapshot/` is generated by `scripts/11_snapshot_vendor_model.sh`.

## What "best model" means here

The best digital twin is not the model with the most triangles. It is the model whose:
- kinematics;
- dynamics;
- actuator timing;
- friction;
- sensor timing;
- camera geometry;
- collision geometry

predict the real rig well enough on held-out trajectories.

The model must carry uncertainty, not just a single nominal number.
